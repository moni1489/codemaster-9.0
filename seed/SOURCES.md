# Источники демо-данных

| Данные | Источник | Допустимость использования |
|---|---|---|
| Филиалы (`branches.json`) | `docs/source/Адреса и контакты филиалов.xls`, `Контакты.docx` (материалы заказчика) | Служебные контакты, опубликованы на действующем сайте. Координаты проставлены разработчиками приблизительно (`coords_verified=false`) |
| Памятные даты (`memorial_dates.json`) | `docs/source/Календарь памятных дат/*.docx` (заказчик), генератор `seed/tools/build_memorial_dates.py` | Материалы заказчика |
| «Об архиве», структура, комплаенс | `docs/source/*.docx`, `Комплаенс служба/` (заказчик), генератор `seed/tools/build_pages.py` | Материалы заказчика |
| Прейскурант (`content/price_list.json`) | Постановление ВКО акимата № 289 от 15.12.2023 (PDF заказчика), набрано по скану | Официальный документ; помечено «сверять с PDF» |
| Каталог (`catalog.json`) | Синтетические записи разработчиков | Вымышленные; персональных данных нет; персоналии — вымышленные/обобщённые |
| Фотографии (12 документов-фото, обложки новостей) | Wikimedia Commons, `seed/photos/` — автор, лицензия и ссылка на каждый файл в `photos.json` | CC BY / CC BY-SA: уменьшены, на изображении подпись «Фото: автор · лицензия»; в карточке — provenance. Современные снимки, не архивные документы |
| Остальные сканы (тексты, карты, газеты, плакат) | Генерируются `api/app/seed/images.py` (Pillow) с водяным знаком «ДЕМО» | Собственная генерация, CC0 |
| Новости, FAQ, выставка, коллекции, хронология (`content/*.json`) | Тексты разработчиков на основе открытых сведений и демо-каталога | Помечены как демонстрационные; общеизвестные даты (1720, 1786, 1991) — открытые сведения |
