# PLAN — прототип сайта Государственного архива ВКО

Источники требований: `docs/source/ТЗ.docx` (далее **ТЗ**), `docs/source/Дополнения к ТЗ.docx` (далее **Д**, приоритетнее ТЗ).
Чек-лист жюри = **Д §4** (минимальная демонстрация) + **Д §6** (сценарии). Решения по противоречиям — `docs/DECISIONS.md`.

Статусы: `—` не начато · `WIP` в работе · `✅` реализовано · `◐` частично · `🎭` имитация/макет (помечено в UI) · `→` следующий этап.

## 3. Этапы

1. PLAN + скелет, docker-compose, Makefile, локальные проверки → пустой стек.
2. Модели + миграции + сид → API каталога с проверкой доступа + тесты S1.
3. Публичный фронт: layout, i18n, тема, главная, каталог, карточка.
4. Справочные разделы и CMS-страницы.
5. Админка: auth, роли, CRUD, workflow, audit, тесты S6–S7.
6. ИИ-помощник + тесты S2.
7. Карта, выставка, история.
8. P2 по остатку времени.
9. Документация и упаковка.
