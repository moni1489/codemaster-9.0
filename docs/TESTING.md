## Условия

- ОС: Windows 11; браузер: Chromium (Playwright 1.49, headless) 1366×900 и 390×844 (мобильный).
- PostgreSQL 16.10 (портативный, локаль БД `en-US`), Python 3.12, Node 24. Docker на машине отсутствовал —
  compose-стек не запускался.

  1 выставка (11 экспонатов), 3 коллекции, 11 событий хронологии.

## Lighthouse

Не измерялся на защищаемой конфигурации (нет production-стека за Caddy на машине разработки). Меры для
целевых ≥ 80: разделение кода по маршрутам (главная ≈ 65 КБ gzip React + чанки страниц), WebP-копии, `loading="lazy"`,
системные шрифты без внешних загрузок. Рекомендуется измерить `npx lighthouse https://localhost/ru` после `make up`.
