# Сценарий показа (7 минут)

Подготовка: `make seed` (или `python scripts/dev.py seed`) — сохранить пароли editor, moderator, branch.ridder,
siteadmin. Открыть две вкладки: сайт `/ru` и админку `/admin` (второе окно — инкогнито для второй роли).
Если сеть нестабильна — в `.env` `LLM_PROVIDER=rule` (помощник в детерминированном режиме с плашкой).
