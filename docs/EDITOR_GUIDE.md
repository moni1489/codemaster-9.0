# Инструкция редактора

Вход: `/admin` → e-mail и пароль. Через 30 минут бездействия сессия завершается (за минуту — предупреждение).
Меню показывает только разделы, доступные вашей роли; права дополнительно проверяет сервер.

## Как проходит согласование

`Черновик` → **Отправить на проверку** → `На проверке` → модератор: **Вернуть на доработку** (`Требует доработки`)
или **Одобрить** / **Одобрить и опубликовать** → `Опубликовано` → **Снять с публикации** или **В архив**.

- Пока материал не опубликован, посетители его не видят.
- Каждое сохранение и смена статуса создают версию (автор, согласующий, дата, комментарий) — «История версий».
- Свой материал согласовать нельзя (принцип четырёх глаз).
- Если редактор правит уже опубликованный материал, он возвращается «На проверку».

## Добавить новость

1. «Новости» → **Создать новость**. Заполните адрес (slug: латиница, цифры, дефисы), категорию, заголовок на
   русском (обязательно), анонс и текст (HTML: абзацы, заголовки, списки, ссылки — опасные теги удаляются).
2. Вкладки KK / EN — переводы (необязательно; без перевода посетитель увидит оригинал с пометкой).
3. **Сохранить** → **Отправить на проверку**. Модератор публикует.

## Изменить справочную страницу

«Страницы» → выберите страницу → правка заголовка, описания для поисковиков и текста по языкам →
отметьте «Обновить дату актуализации» → **Сохранить**. Модератор подтверждает публикацию.

## Добавить документ в каталог (сотрудник архива)

1. «Каталог» → **Добавить документ** → выберите дело (фонд → опись → дело), укажите листы — шифр сформируется сам.
2. Обязательные поля: название (рус.), категория, тип. Остальное — даты (отметьте, подтверждена ли датировка),
   автор, место, тематика, ключевые слова, условия доступа.
3. Новая запись создаётся «закрытой»: описание «Требует проверки», копия «Закрыт».
4. **Цифровые файлы:** выберите PDF/JPG/PNG/TIFF (до 50 МБ), укажите происхождение и права. Тип проверяется по
   содержимому; создаются облегчённые копии, мастер-копия не публикуется; PDF разбивается на страницы.
5. **Отправить на проверку.** Модератор публикует и, если документ не содержит персональных данных, открывает
   доступ к копии в блоке «Статусы доступа» (с обязательным основанием — пишется в журнал).
6. Удаление — только с вводом шифра; ошибочные записи лучше снимать с публикации.

## Выставки и коллекции

Демо-выставка и коллекции загружены сидом. Экспонат ссылается на документ каталога — подпись, источник и права
указываются в экспонате. Редактор выставок в админке — следующий этап (сейчас через API/сид).

## Администратор филиала

«Филиалы» → свой филиал → телефон, e-mail, руководитель, адрес, режим работы, описание (по языкам) → **Сохранить**.
Координаты и показ на карте меняет администратор сайта. Чужие филиалы недоступны (попытка пишется в журнал).

## Журнал действий

«Журнал действий» (администратор): входы, создание/правка/удаление, смена статусов и прав, отказы в доступе.
Фильтр «Отказано» показывает попытки превышения прав.
